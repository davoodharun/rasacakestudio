# Cake Shop website

Name: Rasa Cake Studio
Description: homemade cake shop made by a Sri-Lankan American Immigrant; website displays photos of cake and contact form

## Tech
- Ghost Blog CMS; non technical users should be able to update
- Instagram connectivity; posts/photos on instagram account (personal or business) will sync with site
- include ci/cd and deployment instructions

## Design

- Use modern, minimal, and elegant styling; prefer dark mode stylings
- Use color schemes associated with the Sri Lankan flag
- Company name should be clearly displayed; logo should be created
- you can use examples in /img for sample images
- create a gallery on main page
- fill site with sample text that is fun and engaging
- create contact form to gather customer details and requests
